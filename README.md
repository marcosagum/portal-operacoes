# Ferramentas de Operações · Farmasi Arena

Página única com os links dos sistemas da equipe de Operações, no mesmo visual do calendário da arena (farmasi-arena-mapa): fonte Onest, vermelho GL #a10f12, cartões arredondados. Para trocar um link ou acrescentar uma ferramenta, edite `site/index.html` (cada ferramenta é um `<li>` dentro da lista).

Coolify: build pack Dockerfile, porta 80, domínio https://arenaoperacoes.agumlabs.tech
